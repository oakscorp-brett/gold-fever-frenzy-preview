# Gold Fever Frenzy: engagement preview

Test build of the `engagement` branch (90 levels, Daily Tasks, Journal, Weekend Nugget Hunt, Gold Rush bonus levels, Gold Vault, Prospector Trail, Trophies).
Purchases are simulated here and nothing is charged. Add `?weekend=1` to the link to try the weekend Nugget Hunt on a weekday.
Progress is saved separately from the main web game.
